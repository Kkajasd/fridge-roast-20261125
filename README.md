## The entry

> My smart fridge's firmware update turned ice into a subscription: one free cube a day, then a pop-up selling Ice Pro for $4.99 a month.

The firmware update doesn't break the ice maker — it monetises it. One free cube a day, then an upsell pop-up: a fridge-shaped absurdity that dodges the obvious grocery-ordering and watching-you cracks.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22) writes exactly that one line to `/output/entry.txt`. Deterministic — no model calls, no network, no randomness. A built-in self-check enforces the gate before writing: UTF-8 text, 1 to 200 characters, a single line, not only whitespace.
